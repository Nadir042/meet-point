# 照片保存前预览实施计划

设计依据：`docs/superpowers/specs/2026-11-17-photo-preview-design.md`

## 任务 1：移除首页虚线椭圆

**修改：** `layout.css`

- 删除首页人物插画后方伪元素的虚线椭圆样式。
- 不改动其他虚线边框和地图路线样式。

**验证：** 搜索确认只移除目标选择器，并检查首页实际渲染。

## 任务 2：管理待保存照片状态

**修改：** `journal.js`

- 在手账模块内维护待保存文件及其临时预览地址。
- 多次选择时追加有效文件，并按名称、大小和最后修改时间去重。
- 结合已保存照片数量限制待保存数量，保留现有格式、大小、解码和压缩流程。
- 支持单张移除、保存成功清空、关闭手账清理临时地址。

**验证：** 检查追加、重复、超额、移除、失败重试和清理路径。

## 任务 3：渲染响应式预览区

**修改：** `journal.js`、`journal.css`

- 在上传表单中加入数量状态、缩略图网格、文件名和移除按钮。
- 无待保存文件时禁用保存按钮。
- 桌面端自适应多列，手机端两列，触控目标不少于 44px。

**验证：** 检查桌面和手机布局、键盘焦点与可访问名称。

## 任务 4：回归验证

- 运行 `node --check journal.js`、`npm run check`、`npm test`、`git diff --check` 和界面检测。
- 在本地页面实际选择、追加、移除并保存测试图片。
