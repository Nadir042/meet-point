# 出行需求与活动偏好多选实施计划

设计依据：`docs/superpowers/specs/2026-11-17-multi-select-requirements-design.md`

## 任务 1：数据模型与兼容

- 在 `core.js` 增加交通方式、偏好数组的归一化方法。
- 迁移旧活动的单值字段，校验多选保存数据并保留旧字段兼容。
- 补充核心迁移、互斥和自定义偏好测试。

## 任务 2：推荐与导航

- 演示推荐为每个成员比较所有已选交通方式。
- 真实推荐在有限并发下请求全部所选方式，并保留耗时最短有效路线。
- 搜索和偏好评分读取全部偏好，导航使用候选实际采用方式。
- 补充路线降级、最快方式和多偏好匹配测试。

## 任务 3：共享接口

- 需求接口接受数组字段并继续兼容旧单值字段。
- 投影返回数组和兼容单值字段。
- 更新共享流程测试。

## 任务 4：多选表单与展示

- 将交通方式和活动偏好改为可触控复选选项。
- 实现“不限”互斥、其他需求输入、错误标志和编辑回显。
- 成员表格展示多个选择。

## 任务 5：验证

- 运行语法检查、针对性测试和完整测试。
- 检查窄屏布局、键盘焦点及界面规则。
