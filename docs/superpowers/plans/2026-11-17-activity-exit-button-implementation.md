# 活动退出按钮实施计划

## 目标

在活动详情页现有操作区增加始终可见的“退出活动”入口，并按成员身份和活动状态给出正确反馈。

## 修改

1. 调整 `app.js` 的活动操作区，让发起者和普通成员都显示“退出活动”。
2. 调整 `leave` 点击行为：
   - 普通成员进入现有二次确认流程；
   - 发起者提示先移交权限，并可直接进入活动管理；
   - 投票、暂停、已结束状态显示具体限制原因。
3. 退出成功后返回活动目录，避免停留在已经失去访问权限的详情页。
4. 补充核心退出约束测试，并执行语法检查、测试和差异检查。

## 验证

- 发起者、普通成员和受限状态均能找到退出入口。
- 发起者不能绕过权限移交。
- 普通成员退出后不再属于活动。
- `npm run check`、`npm test` 和 `git diff --check` 通过。
