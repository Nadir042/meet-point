# MeetPoint 工作台编辑式重构设计

日期：2026-11-13  
状态：已确认，待书面复核

## 目标

让工作台与 Landing Page 属于同一个视觉世界：米色与橙粉渐变、暖黑文字、手绘人物和城市手册式排版。保留全部业务功能与当前页面顺序，减少重复圆角框、玻璃层和阴影，建立更清晰的视觉中心。

本轮采用“编辑式工作台 + 艺术章节瞬间”的混合方向：高频操作保持清晰克制，Hero、空状态、推荐理由、结果和日历标题允许使用更大胆的非对称构图与手绘图。

## 当前问题

- 页面外壳、Hero、流程、身份工具、活动卡片、地图、候选列表和日历同时使用圆角表面，层级相互竞争。
- 活动列表是重复卡片网格，不利于快速比较时间、状态和成员。
- 活动详情由多个面板连续嵌套，阅读路径像组件演示而不是一个完整任务。
- 日历虽可用，但大卡片、规则网格和通用月份工具使它接近常见后台模板。
- 工作台与 Landing Page 的手绘人物、编辑排版和艺术气质没有形成连续体验。
- 动效分散，缺少一个有目的的进入与状态反馈节奏。

## 视觉原则

1. 页面只有一张主画布。除地图、弹窗和必须区分的输入表面外，不再给每个内容块单独加卡片。
2. 分组优先使用留白、细线、字号、位置和色块，不使用连续嵌套边框。
3. 珊瑚橙只负责当前主操作、状态纸标签和少量关键数字。
4. 手绘图是章节锚点，不是填充物；每个视区最多一个主要手绘视觉。
5. 动效表达“纸张落位”和“章节展开”，不让所有元素重复弹跳。
6. 手机与电脑保留相同任务顺序和功能，只改变布局密度与插画尺寸。

## 全局工作台框架

- 保留顶部品牌、日历入口、主导航、菜单和账号入口的现有功能。
- 顶部导航继续使用深灰毛玻璃，但减弱独立按钮边框；当前项通过底色、文字和轻微位移共同表达。
- 工作台背景延续 Landing Page 的米色到橙粉色渐变，内容层不再叠加多张大白卡。
- 页面主内容使用统一宽度和纵向节奏。章节之间以 1px 暖灰细线或明显留白分隔。
- 主按钮保留珊瑚橙；次级操作使用文字按钮或轻量描边，不制造多个同等视觉中心。

## 总览页

### Hero

- 取消 Hero 的大圆角卡片与装饰圆环，直接放在主画布上。
- 桌面端使用非对称双栏：左侧标题、说明与“发起一次见面 / 使用邀请码加入”；右侧放置一张较大的手绘人物。
- 手机端改为上下排列，插画缩小并移至标题后的留白区，不挤压主按钮。
- 三步流程改为一条编辑式说明带，使用细线、编号和短文案，不再放进独立容器。

### 活动目录

- “正在参与的活动”从重复卡片网格改成相聚目录。
- 每场活动占一行，展示活动名称、日期时间、类型、成员头像、状态和“进入活动”。
- 行之间只使用留白和细线；桌面端允许名称和元信息分栏，手机端按名称、元信息、成员与操作顺序换行。
- 状态显示为轻微倾斜的纸标签。相邻标签交替使用约 `-1.2deg` 与 `1.2deg`，悬停或聚焦时回正。
- 已完成、进行中、等待和取消状态使用不同明度，不只依赖颜色表达。

## 传统月历

- 保留用户熟悉的七列传统月历和月份切换，不改为时间轴。
- 取消月历外围厚重卡片感，保留一张轻纸面和必要分隔线。
- 月份标题与工具采用编辑页眉，不再像后台筛选栏。
- 活动在日期格中显示为纸质标签，标签轻微倾斜约 `±1.5deg`；日期数字和网格保持端正。
- 珊瑚橙标签表示待参加，米灰标签表示已完成；取消活动使用低对比标签与删除线。
- 同一天最多展示两张标签，超出部分显示“＋N 场”。
- 悬停、键盘聚焦或选中时标签回正并轻微上浮，点击仍打开当天活动。
- 手机端继续保留七列月历；标签缩成可辨识短条，选中日期后在月历下方显示完整活动信息。
- 手绘人物只放在月份标题旁或无活动区域，不覆盖日期、星期和活动标签。

## 活动详情与推荐

- 活动摘要、步骤、结果、地图、候选、成员和投票保持现有业务顺序。
- 活动摘要从独立卡片改为编辑式页眉；状态使用与目录相同的纸标签。
- 进度条取消外部容器，仅保留节点、连接线和当前阶段。
- 已完成结果作为一个明确的横向章节，不额外套白色卡片；导航按钮保持唯一主操作。
- 地图是必要功能表面，继续保留圆角和边界，但降低外围装饰。
- 候选地点在桌面端成为地图旁的编号纸条，手机端排列在地图下方；当前项回正、加深并轻微上浮。
- 成员与投票在桌面端使用两栏编辑区，中间以细线分隔；手机端按任务顺序纵向排列。
- 评分依据、隐私说明和次要管理操作继续使用渐进披露，不在第一视区同时展开。

## 手绘素材

使用用户本轮提供的透明背景图，并在进入代码阶段复制到项目 `assets/`：

- 毕业人物：首次创建、无活动状态或账号完成提示。
- 灯泡人物：推荐理由、候选解释或“为什么推荐”章节。
- 手持票据人物：活动目录、结果确认或路线章节。

素材保持原有手绘笔触；不把它们强行改成统一矢量图。必要时只处理裁切、透明边缘、尺寸与对比度。单个页面不同时出现三张大图。

## 动效

- 页面进入时，主要手绘图从已可见状态轻微上浮并降低模糊，持续约 450–650ms。
- 活动目录按阅读顺序轻微错峰出现，但总延迟不超过 240ms。
- 纸标签落位时从 `±2deg` 过渡到设计倾角；悬停或聚焦时回到 `0deg`。
- 月份切换使用短距离水平滑动与淡化，保持日期位置稳定。
- 地图、投票和表单不添加装饰性持续动画。
- 遵守 `prefers-reduced-motion`，关闭位移、模糊和错峰，只保留状态变化。

## 响应式与可访问性

- 在约 390px 手机宽度与常见桌面宽度分别完成完整流程验证。
- 触控目标至少 44px；标签倾斜不改变点击区域。
- 所有手绘图提供与用途一致的替代文本；纯装饰图使用空替代文本。
- 当前导航、活动状态和月历选中状态不只依赖颜色。
- 文字放大到 200% 时，活动目录、月历工具和主操作不得重叠或被裁切。
- 键盘焦点使用清晰暖黑/珊瑚外框，标签在聚焦时回正。

## 数据与行为边界

- 不修改活动、成员、需求、推荐、投票、地图、相册或账号 API。
- 不改变工作台现有四个主要入口和相聚日历入口的含义。
- 不改变传统月历的月份、日期和活动选择逻辑。
- 不新增付费服务、网络字体或新的前端框架。
- 不用手绘图替代地图、路线、状态或错误信息等真实数据。

## 验收标准

1. 总览页第一视区不再由多层圆角卡片构成，标题、主操作和手绘视觉在数秒内可识别。
2. 活动列表以目录式行布局呈现，状态、时间、成员和入口可快速比较。
3. 传统月历保留七列结构，活动以轻微倾斜纸标签呈现，交互时回正。
4. 活动详情显著减少嵌套框，但地图、投票、成员、导航和管理功能完整。
5. 三类手绘素材各有明确用途，不造成文字遮挡或视觉拥挤。
6. 动效具有统一节奏，并在减少动态偏好下关闭。
7. 手机和电脑端均能完成创建、加入、填写需求、推荐、投票、查看日历与打开导航。
8. 现有语法检查、单元测试与地图访问控制测试继续通过。

## 验证

- 对总览、活动目录、日历、推荐中、已完成和空状态进行浏览器截图审查。
- 检查约 390px 手机、平板宽度和桌面宽度。
- 使用键盘完成导航、活动进入、月份切换、日期选择和弹窗关闭。
- 开启减少动态偏好，确认内容不依赖动画出现。
- 运行 `npm run check`、`npm test` 和 Impeccable 检测；只修复本轮改动引入的问题，不清理无关历史代码。
