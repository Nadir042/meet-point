# MeetPoint · 让每个人都离相聚更近一点

MeetPoint 是一个面向多人出行的集合点推荐 H5 演示项目。发起者创建活动并邀请伙伴，成员提交出发地、交通方式和偏好后，共同查看候选地点、投票决定集合点，并在日历和手账中记录这次相聚。

当前版本为 **0.3.0（Sprint 1 Demo）**。新建活动支持通过同一服务在不同浏览器或设备间协作；地图与路线等仍使用演示数据。

## 功能概览

- **活动协作**：创建活动、邀请码加入、管理成员和活动状态。
- **需求与推荐**：提交出行需求；按“最公平、最合口味、最方便”展示三组 Top 3 候选。
- **共同决策**：申请重新推荐、审批、多轮投票、改票、确定最终地点，并提供外部高德导航入口。
- **日历与手账**：按日期查看活动，记录照片、感受和留言。
- **身份与恢复**：支持游客身份及账号注册、登录；可将持有凭证的游客活动归入账号。

## 快速开始

需要 **Node.js 22.13 或更新版本**。项目使用 Node.js 内置模块，当前无需安装额外依赖。

在项目根目录运行：

```powershell
npm run start
```

浏览器访问 <http://localhost:3000/index.html>。首次运行会自动创建 SQLite 数据库 `data/meetpoint.sqlite`；`data/` 已被 Git 忽略。

如需修改监听端口，可在启动前设置 `PORT`。默认仅监听本机 `127.0.0.1`。在可信的局域网内用其他设备演示时，可设置 `HOST=0.0.0.0`，再使用运行服务的电脑的局域网 IP 和端口访问。例如在 PowerShell 中：

```powershell
$env:HOST = '0.0.0.0'
npm run start
```

## 数据与当前边界

- 新建共享活动及其手账、照片由 Node.js 服务和 SQLite 保存。服务端校验成员凭证，并隐藏其他成员设置为私密的出发地。
- 游客未完成活动从最近一次有效操作起可恢复 24 小时，账号成员为 7 天；已完成或取消的活动记录不按此期限清理。浏览器保存游客身份和活动凭证；清除浏览器数据可能使游客无法恢复活动。
- 本机示例、反馈和自定义头像仍保存在当前浏览器。反馈不会发送给团队，管理员处理流程尚未接入共享服务。
- 地图、路线、出行时间和评分使用模拟数据；高德导航是外部跳转，尚未接入真实地图 API。评分权重是演示规则，详见[更新日志](CHANGELOG.md)。
- 当前实现用于课程演示。正式部署还需要 HTTPS、访问频率限制、数据库备份，并应评估用安全的 HttpOnly Cookie 保存登录状态。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `index.html`、`app.js`、`styles.css`、`layout.css` | 页面入口、交互与界面样式 |
| `core.js` | 活动、推荐和投票等业务规则 |
| `journal.js`、`journal.css`、`media.js` | 日历、手账与照片处理 |
| `server.js`、`shared-store.js` | HTTP 服务、共享活动与 SQLite 存储 |
| `tests/` | 业务规则与共享流程测试 |
| `docs/` | 需求、架构、数据库与项目计划资料 |
